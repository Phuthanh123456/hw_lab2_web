## Rules for adding an entry

Record an issue only when an AI-generated or AI-proposed change has concrete evidence and the failure has been reproduced or otherwise verified. Do not invent, seed, or infer failures. Keep prompt/output references and test evidence available without including secrets.

## Verified failure entry template

Copy this section once for each independently verified issue.

### Failure N — short factual title

- **AI source:** Link or identify the generated/proposed code, response, or commit.
- **Evidence:** File and line, diff, captured output, or reproducible test that demonstrates the problem.
- **Observed failure:** What happened, and under which conditions.
- **Detection method:** Test, review, runtime observation, or tool that first exposed it.
- **Correction:** The change that fixed the verified issue.
- **Regression check:** Exact test or command used to confirm the correction.
- **Result:** Actual observed outcome and date.
