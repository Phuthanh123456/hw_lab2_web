# Homework 1 — Production Enterprise Data-Grid

React + TypeScript implementation built with Vite.

## Requirements

- Node.js and npm

## Install and run

    npm install
    npm run dev

## Typecheck and production build

    npm run typecheck
    npm run build
    npm run preview

The demo includes a semantic data grid with sorting, filtering, pagination, keyboard cell navigation, and row selection. Accessibility audit artifacts and verification notes are in artifacts/ and TASK_DECOMPOSITION.md.
