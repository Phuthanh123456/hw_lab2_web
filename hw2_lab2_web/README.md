# Homework 2 — Concurrent FIFO Audio Visualizer Queue Engine

TypeScript browser demo built with Vite. It includes the FIFO audio task queue, cancellation, decoding, playback, and Canvas frequency visualizer.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Install and run

    npm install
    npm run dev

## Typecheck, tests, and production build

    npm run typecheck
    npm test -- --run
    npm run build
    npm run preview

See TASK_DECOMPOSITION.md for milestone status and verification notes.
